# 可配置数据

数值都在 `Assets/_Project/Content/Slice` 里，选中资产后用 Inspector 改。拼船布局用菜单 **星际商船 / 拼船面板**，不要改场景里的坐标。

坐标：x 从左到右，y 从下到上，都从 0 计。面板上排是 y 较大的一侧。从左侧拖出舱室时，光标下的格子是该舱的左下角。拖已有的舱时，抓住的那一格保持在光标下。拖出格子即拆掉。

供电：反应堆放得下就供电。功能模块必须和反应堆上下左右连通才有能源，否则不工作。连通时，功能模块自己就能当通道。通道只用来补空档，装甲带会把路挡住。连通之后按拼船方案列表的顺序分电。电不够的舱不提供推力、散热、武器、气阀和损管，质量仍然计入。

拼装规则：必须有舰桥、主推和反应堆。舰桥和主推没连上反应堆时显示没有能源，连上了但电不够时显示没有电。散热和损管有作用范围，范围内的舱才会吃到散热或损管。距离从本舱任意一格量到目标舱任意一格，斜向也算。

## 武器 `WeaponDef`

资产：`Content/Slice/电磁炮.asset`、`Content/Slice/导弹.asset`。电磁炮在射程内、炮口大致朝向目标就发射。命中在飞出去之前算好：基准 × 横截 × 锁定。横截由距离和两边的相对速度决定，越远、相对越快越难中。操作者还没进战斗，按 1 算。锁定要炮口持续对着目标才涨满，没锁上就打不中，急转会掉锁。算中的炮弹按提前量飞进目标，没算中的从旁边飞过，不再飞出去之后再碰运气。世界速度仍是舰速加上射出速度。先扣打中那一格的装甲，剩下的扣船体结构。导弹不看舱口朝向，敌船进入射程就会朝它发射。导弹先以慢速离开船体，再在加速时间里加到最快，并转向目标。加速时间在导弹的 boostTime，当前 1.5 秒，0 就是一出发就最快。发射时按基准命中掷一次：掷中就咬住船体，没掷中就往侧面弯开，擦过也不造成伤害。打中后按爆炸半径再伤周围的格子。

| 字段 | 含义 | 电磁炮 | 导弹 |
| --- | --- | --- | --- |
| muzzleSpeed | 相对船的射出速度，米/秒。世界速度 = 舰速 + 射出速度 | 80 | 36 |
| cooldown | 两次射击间隔，秒 | 0.9 | — |
| baseHit | 炮台基准命中，0 到 1 | 0.75 | 0.55 |
| lockPerSecond | 锁定每秒增长 | 0.35 | 0.5 |
| penetration | 穿透。每穿一格消耗一次 | 3 | 1 |
| damage | 打进舱室的伤害 | 12 | 16 |
| homing | 飞行中转向目标 | 关 | 开 |
| homingTurnRate | 每秒最多转过的角度 | 0 | 140 |
| boostTime | 导弹从离舰慢速加到最快速度的时间，秒。0 是一出发就最快 | — | 1.5 |
| lifetime | 飞行秒数，超过自毁。0 为不限 | 0 | 8 |
| blastRadius | 爆炸半径，格 | 0 | 1 |

## 重力井 `GravityWellDef`

三份资产密度相同，半径按质量的立方根缩放。飞船长 20 米，大型行星直径 1000 米，是飞船的 50 倍。影响半径 = 井宽 × 质量。引力常数和井宽随半径一起放大，掠过时速度的增减仍和放大前同一量级。

| 资产 | 显示名 | 质量 | 半径 | 影响半径 | 颜色 |
| --- | --- | --- | --- | --- | --- |
| 小型行星 | 小型行星 | 2 | 198.4 | 366 | 浅褐 |
| 岩石行星 | 中型行星 | 8 | 315 | 1464 | 褐 |
| 大型行星 | 大型行星 | 32 | 500 | 5856 | 暗褐 |

| 字段 | 含义 |
| --- | --- |
| mass | 行星质量。引力和重力井按它放大。侧着掠过时，弯也由它决定 |
| gravityConstant | 加速度 = 引力常数 × 质量 / 距离²。三颗都是 91340 |
| wellSpan | 影响半径 = 井宽 × 质量，米。外面不拉船。三颗都是 183 |
| floorRadius | 行星半径，米。画面上的星球就是这个大小。飞船挨到球面就会撞毁，航迹也停在这里 |
| bodyColor | 星球颜色 |

## 界面

拼船界面是 `UI/AssemblyPanel.uxml` 和 `UI/AssemblyPanel.uss`。用 **Window / UI Toolkit / UI Builder** 打开 uxml 改栏宽、字号和颜色。格子和舱室按钮由数据生成，不写进 uxml。

编辑布局：菜单 **星际商船 / 拼船面板**，或播放 `Scenes/CombatArena`。两种地方都是把左侧舱室拖到船壳上。船壳区域滚轮或右上角的加减可以缩放，放大后用滚动条挪画面。播放时的改动会写回玩家拼船方案。

字号保持在 20 左右，不随缩放变小。格子里写不下整名时，只显示第一个字。气阀和通道叠在同一格时，点气阀那一半拖气阀，点另一半拖通道。

拼船面板右上角「开战」进入当前战场。点一下 W 加一档推进，点一下 S 减一档，最低是空档，没有倒车。按住大约每 0.5 秒再切一档，松手停在当前档。引擎只沿喷口方向推。要往反方向飞，先把船转 180 度再推进。没有单独的速度上限，快慢由引擎一直加上去的速度，再加上弹弓留下的速度一起算出来。A D 转向按住就朝满转加速，松开后角速度按这具船体的惯性停下来。惯性在船体上，单位是秒，0 是立刻停。船头每转 1 度，已有速度跟着转 0.5 度，侧滑大约少一半；速度大小不变。不转的时候，直线空档仍完全滑行，只有推力和行星引力能改变速度。满档加速度大约每秒 10 米。主推的白边是喷火方向。电磁炮在射程内、炮口大致对着就会按提前量射击。左键点选敌船后会出现正方形框，点选和右键都按这个正方形的实际范围判断。方框面积内右键就会弹出菜单。再按右键、拖动地图或滚轮缩放会关掉菜单。左键点菜单项不会关掉菜单。双击敌船，镜头改为跟踪敌船。跟踪自己或敌船时，滚轮缩放不解除跟随。只有按住左键拖动地图才会解除跟随。主角的飞行曲线在船不在画面里时仍然画出穿过画面的一段。进入战斗后，敌舰也一样，看不到船也继续画穿过画面的红线。手动、跟踪、平行、环绕、脱离。跟踪贴在敌舰航向后面，平行贴在侧面，环绕绕着敌舰飞，脱离拉开到选定距离。命令每帧按我舰、敌舰的位置和敌舰速度重算，直到相对位置满足指令。平行贴在侧面，跟踪贴在后面，环绕绕着飞，脱离则拉开到选定距离后不再靠近。喷口和需要补的速度差在大约
